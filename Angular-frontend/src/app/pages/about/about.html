About MobBuyLab

MobBuyLab is a simple e-commerce web application developed using Angular, Bootstrap, and TypeScript. The project provides users with an easy and interactive way to explore the latest mobile phones and laptops.

Product information is retrieved dynamically from external REST APIs, allowing users to view product images, prices, ratings, discounts, stock availability, and detailed specifications in real time.

The application includes separate sections for mobiles and laptops, detailed product pages, responsive navigation, and a user-friendly interface designed with Bootstrap components.

Technologies Used

  • Angular
  • Bootstrap
  • TypeScript
  • HTML & CSS
  • REST API Integration

API Sources

  • Smartphones API (DummyJSON)
  • Laptops API (DummyJSON)
